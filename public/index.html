OFFLINE CANON

Bundled kjv.json Corpus

All 66 books, 1,189 chapters, and 31,102 verses of the public-domain King James Version are bundled directly in the app binary—zero network requests, zero latency, and complete privacy.

SWIFTDATA ANNOTATIONS

5-Color Highlights & Bookmarks

Tap one or multiple verses to apply translucent Yellow, Green, Blue, Pink, or Orange highlights or ribbon bookmarks. Every annotation is persisted locally using iOS 17 @Model SwiftData containers.

ERGONOMIC NAVIGATION

Searchable Book Picker & Swipes

Tap the navigation title to search any book and jump directly to a chapter grid, move across chapters with horizontal swipe gestures, and automatically resume right where you left off.

NATIVE SWIFTUI + SWIFTDATA

Clean, Zero-Dependency Xcode Project

Built with Xcode 16 synchronized folders, @Observable state management, and SwiftData queries filtered per chapter for smooth 120Hz ProMotion scrolling.

// Project Structure (Xcode 16+ / iOS 17.0+)
BibleReader/
├── BibleReaderApp.swift      // App entry & SwiftData ModelContainer
├── Models/
│   ├── BibleStore.swift      // Loads kjv.json, clamping & citation formatting
│   ├── ReaderState.swift     // Persisted chapter location & scroll anchor
│   └── Annotations.swift     // @Model Bookmark & Highlight + 5 swatch colors
├── Views/
│   ├── ContentView.swift     // TabView (Read & Saved)
│   ├── ReaderScreen.swift    // ChapterView, VerseRow, SelectionBar
│   ├── BookPickerView.swift  // Searchable book list & chapter grid
│   └── SavedScreen.swift     // Bookmarks & highlights with deep-link jump
└── Resources/kjv.json        // Complete KJV text (66 books, 31,102 verses)
